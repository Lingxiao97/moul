# MCP 管理平台使用说明

## 功能特性

1. **服务器管理**
   - 查看所有可用的 MCP 服务器
   - 显示每个服务器的资源数量
   - 服务器状态监控

2. **资源浏览**
   - 列出所有 MCP 资源
   - 按服务器筛选资源
   - 搜索资源（按名称、URI、描述）

3. **资源查看**
   - 查看资源详情
   - 预览资源内容
   - 下载资源

## 使用方法

1. 访问 `/mcp` 页面
2. 点击"刷新"按钮加载服务器列表
3. 点击服务器卡片展开查看资源列表
4. 点击资源项查看详情和内容
5. 使用搜索框和筛选器快速找到需要的资源

## 技术说明

- 前端使用 Next.js 14 + React + TypeScript
- UI 使用 Tailwind CSS
- 图标使用 Lucide React
- API 路由处理服务器端逻辑

## 注意事项

MCP 资源的实际获取需要通过 MCP 工具调用。在当前的实现中：
- 服务器列表从配置中获取
- 资源列表需要通过 MCP 工具调用获取
- 资源内容需要通过 MCP 工具调用获取

如果需要实际获取 MCP 资源，需要：
1. 在服务器端建立与 MCP 服务器的连接
2. 使用 MCP 协议进行通信
3. 调用相应的工具获取资源列表和内容
